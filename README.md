# 💻 Object-Oriented Programming (OOP) in Python

A comprehensive collection of Object-Oriented Programming principles implemented in Python. This repository serves as a foundational reference for building modular, scalable, and production-ready software architectures.

## 🚀 Overview
Mastering OOP is critical for writing clean, reusable code—especially when structuring complex Data Science pipelines, building custom AI/ML models, or developing data processing modules. This repository breaks down core OOP concepts into practical, easy-to-understand Python scripts.

## 📚 Core Concepts Covered
* **Classes & Objects:** Creating blueprints and instantiating objects.
* **Encapsulation:** Data hiding, access modifiers (public, private, protected), and property decorators (Getters/Setters).
* **Inheritance:** Single, multiple, and multi-level inheritance to promote code reuse and modularity.
* **Polymorphism:** Method overriding, method overloading, and dynamic behavior scaling.
* **Abstraction:** Utilizing Abstract Base Classes (`abc` module) to enforce strict design patterns.
* **Dunder/Magic Methods:** Customizing built-in Python behaviors (e.g., `__init__`, `__str__`, `__len__`).

## 📂 Project Structure

```text
├── encapsulation/      # Scripts demonstrating data privacy and property decorators
├── inheritance/        # Examples of single, multiple, and hierarchical inheritance
├── polymorphism/       # Method overriding and operator overloading examples
├── abstraction/        # Abstract Base Classes implementations
├── classes_objects/    # Foundational class creation and instantiation
└── README.md           # Project documentation
```
